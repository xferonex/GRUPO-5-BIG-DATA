Servicio Descripción
EC2Servicio básico de la nube AWS. En EC2 se crean las máquinas virtuales en la nube. Permite su creación de forma rápida. Además, si la máquina virtual se queda corta, se puede reescalar añadiendo más potencia fácilmente.
RDSServicio de AWS relacionado con BBDD o motor de base de datos relacional de AWS, en lugar de disponer de este servicio on premise sobre un servidor, es alojado en el Cloud de AWS, un ejemplo puede ser Postgresql o MySQL.
S3Almacenamiento de AWS alojado en Cloud, útil para llegar a los datos desde distintos servicios de AWS, por ejemplo: Una página expuesta en Cloudfront de AWS, el usuario accede a esa web y tras hacer login quiere consultar una información, esta información está alojada en un Bucket de S3. Backups de un servidor sql server alojados en una instancia ec2, requieres que se sincronicen en S3 para mantener información redundada.
EBSServicio de almacenamiento de AWS, más enfocado u orientado a la instancia EC2, a modo de unidad de red o volumen, lo definiría como un disco duro conectado a la instancia ec2
DynamoDBTipo de BBDD de AWS, junto con Aurora son servicios de BBDD de AWS, en este caso DynamoDB no es BBD relacional. En el caso de Aurosa si es relacional.
CloudFrontServicio de AWS muy orientado a programación web, sirve para copiar el contenido de la web en distintos servidores por distintas ubicaciones, es muy rápido y muy seguro, dentro de la arquitectura de AWS podrías definir páginas Web así como exponerlas al exterior, pueden ser protegidas por el propio WAF de AWS
Amazon EKSServicio de AWS para la gestión de Kubernetes, en este punto tengo dudas entre Docker y Kubernetes, desde el punto de vista de AWS, EKS sería el servicio que ayuda a administrar los Kubernetes.
AWS LambdaServicio de AWS que compararía con un demonio dormido, un desencadenante en Cloudfront permitiría a este servicio despertar y ejecutar el código que se le hubiese subido. La gracia de este tipo de servicios es que se paga por uso, mientras el servicio esté parado no está facturando.
Amazon QLa IA de Amazon o un asistente de IA de Amazon instalable en Visual Studio Code, muy útil para ayudar a depurar o investigar código en distintos lenguajes, por ejemplo muy útil para combinar html CSS y Phyton con Java Script
CloudwatchAlgo similar a un monitor de eventos o servicio de monitorización de eventos de Amazon, mucho más elaborado que un Nagios y más vistoso, ayuda a gestionar alertas de los distintos servicios alojados en las distintas VPC.
CognitoGestión de identidades de usuarios para aplicaciones, ejemplo, app web publicada al exterior que requiere registro de usuarios, contraseñas y MFA, cognito sería la solución a esta necesidad, sería la herramienta que ayuda a validar a los usuarios.
