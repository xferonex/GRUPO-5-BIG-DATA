Tabla Servicios AWS

Servicio Descripción
EC2Servicio básico de la nube AWS. En EC2 se crean las máquinas virtuales en la nube. Permite su creación de forma rápida. Además, si la máquina virtual se queda corta, se puede reescalar añadiendo más potencia fácilmente.
RDS Servicio de AWS relacionado con BBDD o motor de base de datos relacional de AWS, en lugar de disponer de este servicio on premise sobre un servidor, es alojado en el Cloud de AWS, un ejemplo puede ser Postgresql
S3 Servicio de almacenamiento muy útil para alojar información que tengas en distintos servicios de aws y disponer de ella al momento, es escalable y seguro, útil para llegar a los datos desde distintos servicios de AWS. por ejemplo: Una página expuesta en Cloudfront de AWS, el usuario accede a esa web y tras hacer login quiere consultar una información, esta información está alojada en un Bucket de S3. Backups de un servidor sql server alojados en una instancia ec2, requieres que se sincronicen en S3 para mantener información redundada.
EBS Servicio de almacenamiento de AWS, más enfocado u orientado a la instancia EC2, a modo de unidad de red o volumen, lo definiría como un disco duro conectado a la instancia ec2
DynamoDB Tipo de BBDD de AWS, junto con Aurora son servicios de BBDD de AWS, en este caso DynamoDB no es BBDD relacional. En el caso de Aurora si es relacional. DynamoDB es útil para aplicaciones que requieren alta disponibilidad y escalabilidad.
CloudFront Red de distribución de contenido (CDN) de AWS desde servidores globales para que llegue más rápido, seguro y con menor latencia a los usuarios.
Amazon EKS Servicio de AWS para la gestión de Kubernetes. Facilitando la implementación, escalado y operación de clústeres de Kubernetes.
AWS Lambda Su funcionamiento se podria comparar con un servicio que permanece inactivo a la espera del desencadenante que lo active. La gracia de este tipo de servicios es que se paga por uso, mientras el servicio esté parado no está facturando.
Amazon Q La IA de Amazon o un asistente de IA de Amazon instalable en Visual Studio Code, muy útil para ayudar a depurar o investigar código en distintos lenguajes, por ejemplo muy útil para combinar html CSS y Phyton con Java Script
Cloudwatch Algo similar a un monitor de eventos o servicio de monitorización de eventos de Amazon, mucho más elaborado que un Nagios y más vistoso, ayuda a gestionar alertas de los distintos servicios alojados en las distintas VPC.
Cognito Gestión de identidades de usuarios para aplicaciones, ejemplo, app web publicada al exterior que requiere registro de usuarios, contraseñas y MFA, cognito sería la solución a esta necesidad, sería la herramienta que ayuda a validar a los usuarios.
